## 3. Q1 方法审查

### 3.1 可保留的正式方案与结论

正式流程：保留全部原始视频及官方标注 → 解码媒体并记录时间信息 → 16 kHz单声道音频与实际视频帧PTS → 同样本Whisper时间戳及文本来源审计 → 冻结RoBERTa、WavLM-base-plus、SigLIP2 → 原生特征/时间锚点 → 50个公共时间窗最大重叠硬映射 → 特征矩阵、各模态mask及来源记录。

对样本时长D，公共窗为B_k=[kD/50,(k+1)D/50)。对原生区间I_j，计算正重叠长度，选择重叠最大者；并列时按中心距离、原生索引决胜。无正重叠则输出零向量，mask为false；有效零值与无观测不能混用。

这个规则确定、轻量、可回溯，不是简单地把矩阵resize到50行。选择hard的主要理由是正时间交集和单来源可追溯性，不应写成“它在预测指标上最优”。现有对照中nearest-center的四项probe均值略好，但存在152个文本有效bin引用了与该bin不相交的来源；hard没有这种规则性问题。

最终汇总数字为：文本/语音/视觉有效bin覆盖率82.42% / 99.10% / 100%；75条采用官方文本映射，25条采用同样本media-ASR；最终选用文本特征有21个粗segment回退区间，原始ASR审计中有46个回退词。两种计数分母不同，不得混写。来源为`outputs/q1_final_local/00_manifest/q1_paper_numbers.json`。

### 3.2 必须修正或限定的表述

1. **处理完成率不等于文本正确率或精确对齐率。** 100/100说明文件和流程覆盖；82.42%是有效bin覆盖，不是82.42%的词时间戳正确。视觉100%覆盖也与相邻帧中点扩展支持区间的定义有关，不代表每个时刻都实际采帧。
2. **时间锚点不等于编码器仅使用该短区间。** WavLM代码取`last_hidden_state`，却按卷积前端hop/receptive field记录输出位置；RoBERTa词表示也使用上下文。论文应称“输出位置的时间锚点/映射区间”，不能据此宣称向量只包含25 ms语音或单个词的信息，也不能直接当作严格局部因果证据。
3. **公共窗内对齐是粗粒度对应，不是逐词逐声精确同步。** 典型bin24中，文本life区间为10.90–11.12 s，音频锚点为10.840–10.865 s，选中视频帧为10.733333 s；三者各自与同一公共窗有关，但不必彼此重叠。图注要说明这一点，避免把公共窗的三个代表特征说成同一瞬间。
4. **保留官方文本与标注，并区分ASR派生输入。** 同视频ASR是允许的原始媒体特征处理，不应叙述为修改官方文本或标签；不能仅凭ASR不一致断言官方标注错误。低可信样本必须保留及标记。
5. **文本审计口径需补来源衔接。** 早期`q1_text_final/report.md`记录text_valid=68/100、low_confidence=32；最终特征汇总记录75条official映射。二者字段和阶段不同，不能直接判为数值矛盾；但正式`text_feature_sources.json`及来源选择规则未包含在当前包，尚不能从交付内容独立重建68→75的转换。补齐清单和规则，而不是默默删掉旧数字。
6. **Q1辅助CV不是独立泛化证据。** 本次直接检查25折ID，25/25折都有train/test同video_id重叠，重叠视频组8–16个/折，13–20条测试clip/折来自训练中出现过的视频。故不能把25折当成25个独立实验，不能将sample bootstrap区间当成跨视频泛化的显著性证明。现有报告已大体保留限制，正文应同样谨慎。

若坚持声称“在未见视频上显著优于某方法”，需另行评审以video_id分组的验证方案；但Q1官方任务并不要求此结论。将probe降为辅助诊断即可，无需为收口重跑。

### 3.3 已有实验是否足够

已有三种对齐规则、时间偏移敏感性、七种模态组合、视觉编码器单变量比较、文本质量感知规则比较，足以说明方案选择。无需再加大型视觉编码器、forced alignment整套替换或复杂融合网络。

可写的实测结论是：hard在可追溯性和复杂度上合理；三模态没有统一优于双模态；文本质量加权没有带来一致改善；保留正式冻结方案。不能写成“三模态融合全面优于单模态”“hard显著最好”“更大预训练模型一定更好”。

## 4. Q2 方法与证据审查

### 4.1 架构和数据处理正确性

Q2使用官方aligned_50：文本768维、语音74维、视觉35维。有效长度来自`text_bert[:,1,:]`；只用于padding组织，不是把text_bert作为第四模态。原生零值、人工缺失、padding三者分开。人工availability/native-zero标记未作为模型可见特征，避免了用人工干预真值帮助预测。

对每个模态m，B0计算有效位置均值，再通过Linear→LayerNorm→GELU→Dropout映射到128维，三路拼接为384维，MLP融合后输出3分类logits与1个连续值。类别权重来自训练集，损失为WeightedCE+SmoothL1，lambda_reg=1。

P2保留B0，另设逐模态标量注意力：

    alpha_mt = softmax_t(w_m^T x_mt + b_m)，仅屏蔽padding
    h_m = P_m(mean_valid(x_m)) + gamma_m P_m(sum_t alpha_mt x_mt)

P_m是同一个冻结B0投影。B0投影、融合及双头参数冻结且保持eval，gamma零初始化，仅训练883个附加参数；P2总参数164343，B0总参数163460。训练仍使用完整样本，无BlockMask增强。gamma可为负值，不是[0,1]概率或模态可靠性权重。

架构没有显式位置编码或跨时刻交互，池化对有效特征行的重排不敏感；官方特征本身可以携带上下文信息。应称“注意力残差池化”，不要称“连续缺失片段重建网络”“时序依赖恢复”“可靠性门控融合”。注意力图可作为模型内部诊断，不能自动当成Q3忠实解释证据。

### 4.2 验证协议及其边界

- 本次通过附件2标签表核对，train/valid/test分别有1528/239/381个video_id，三对划分的video_id交集都为0。历史审计还记录样本ID跨split无重复、三模态完全相同特征无重复。video_id分离不等于已证明speaker分离，不能扩张结论。
- 固定基准含clean及54个场景：3模态×5缺失率×3位置=45；3种双模态组合×1缺失率0.3×3位置=9。双模态采用相同相对位置；不是随机独立起点，也没有覆盖所有多段/三模态缺失组合。
- 缺失长度为max(1,round(rho L))，Python half-to-even取整；实际比例为整数长度/L。训练seed是42/43/44；20260923是固定benchmark标识，场景起点由early/middle/late规则确定，不能说做了54次随机独立试验。
- aligned_50的位置并无原始逐词秒级时间戳，所以Q2的rho表达有效特征位置占比，不应直接换算为物理秒数。Q1公共50窗与此不是同一种时间接口。
- 项目内部选模分数S=0.25Accuracy+0.25Macro-F1+0.25(1−MAE/6)+0.25(Pearson+1)/2；R=0.5S_clean+0.5mean(S_missing)。它们不是官方综合评分。正文以四个官方指标为主，S/R只解释模型选择。
- 同一验证集用于结构/参数/epoch选择，符合赛题明确用途，但得分属于开发验证结果，不是独立测试泛化估计。54个场景共享728个样本，不能据其数量放大样本量或做独立重复显著性检验。

### 4.3 最终结果及正确结论

下表来源：`E2026/outputs/metrics/b5_p2_multiseed_summary.json`；数值是三个训练seed的均值±样本标准差，缺失条件先在各seed内平均54场景。

| 条件 | 模型 | Accuracy↑ | Macro-F1↑ | MAE↓ | Pearson↑ |
|---|---|---:|---:|---:|---:|
| clean | B0-WCE | 0.6401±0.0048 | 0.6139±0.0091 | 0.6079±0.0103 | 0.6409±0.0043 |
| clean | B5-P2 | 0.6419±0.0057 | 0.6241±0.0026 | 0.6059±0.0066 | 0.6472±0.0025 |
| 54场景平均 | B0-WCE | 0.6349±0.0062 | 0.6092±0.0075 | 0.6111±0.0098 | 0.6359±0.0038 |
| 54场景平均 | B5-P2 | 0.6340±0.0049 | 0.6163±0.0012 | 0.6091±0.0060 | 0.6414±0.0025 |

R由0.741677±0.001458提高至0.744777±0.001492；逐seed配对增量为+0.005600、+0.003791、−0.000090，均值+0.003100、样本SD=0.002907。

**建议正文结论：**“在冻结的局部连续缺失验证基准上，注意力残差池化以883个附加可训练参数带来小幅平均综合收益，缺失条件下Macro-F1、MAE和相关性均值改善，Accuracy略降；收益在两个seed中出现，另一seed基本持平，说明改善具有一定初始化敏感性。”

必须披露三点：

1. 缺失Accuracy均值从63.4887%到63.4013%，下降约0.0873个百分点。不能写“四指标全面提高”。
2. P2的clean→missing综合分数降幅为0.004781，B0为0.003237。P2在缺失条件下绝对分数较高，但其相对自身clean的衰减更大；所以“更高缺失性能”与“更小缺失退化”是两个结论，后者不受当前数据支持。
3. 原生视觉全零子组只有15个验证样本；seed42/43的P2分类指标下降，seed44接近不变，应作为失效模式。含文本的双模态缺失平均改进也很小，不能宣称强缺失全场景稳定获益。

本次额外从已有best-clean记录重算了共同选模标准的敏感性对照：B0与P2都按clean S选checkpoint时，配对R增量为+0.005435/+0.003791/−0.000090，均值+0.003046±0.002837。由此可说明主结果的小幅增益并非仅由“B0按clean选、P2按robust选”的规则差异造成。此项没有重新训练，没有替换锁定模型；但训练阶段、早停等仍不完全相同，不能描述成端到端完全等预算架构比较。

### 4.4 实验充分性判断

现有B0/B1/B2三seed对比、重建路线及其多seed复核、池化P0/P1/P2、P2三seed、融合/任务权重/标准化筛选和失效诊断，已经较充分。无需为了“创新性”再增加模型或把全部失败分支写成长篇实验史。

本文能够支持的是该冻结验证网格上的有限改善。若需要扩展成“对任意随机缺失均稳健”，可预先固定一个独立随机起点/不重合双模态缺失压力测试，仅用锁定模型作补充评估；这是增强外推证据的可选项，不是官方必需，也不能再据它选择模型或调参。附件2 test一次性锁定后评估同样可作为可选补证，不是替代附件3交付的手段。本轮不执行这些新增流程。

- 线性回归头不自带[-3,3]范围约束。最终推理应检查输出范围，明确是否保持原输出或采用预先确定的clip规则；若改变后处理，验证集报告须使用同一规则。不能根据附件3分布调阈值或修结果。

## 6. 正文应怎样组织

### 6.1 总体叙事

论文主线可写为：“面向不同模态采样尺度，构造可追溯的时间特征接口；基于官方大样本特征，在保留基础模型的情况下以轻量残差池化改善局部缺失预测；进一步在问题三研究证据解释。”

必须画出两个数据入口：附件1→Q1自生成特征；附件2→Q2训练验证→附件3推理。Q1三模态维度都是768，Q2为768/74/35；两者既不是同一特征集，也没有实际验证过的串联训练关系。不能为了叙事连贯虚构“Q1特征送入Q2训练”。

### 6.2 Q1建议6个小节

1. **数据与时间接口。** 100条/37个视频组、样本ID、原始媒体保留、真实PTS、音频采样及50窗定义；交代异常样本不删除。
2. **三模态特征。** 三编码器及版本、输入/输出维度、文本来源选择、subword到词向量、16 kHz语音、4 fps视频；说明文本/语音为上下文表征而不是手工情绪维度。
3. **最大时间重叠数学模型。** 区间定义、重叠式、argmax、并列规则、零填充/mask、trace字段；给出伪代码或简洁算法框。
4. **全量结果与质量。** 正文完整100行或按样本双栏排版的结果表；共同模型名、维度、K写在表头，逐样本列ID、时长、三模态有效步数/覆盖、文本来源/异常。随后报告覆盖、有限值和来源完整性。
5. **典型样本与异常处理。** 至少一张真实媒体对齐图；另用一个小案例解释官方文本与媒体观测不一致时的处理及限制。
6. **对照验证、复现与局限。** hard/nearest/weighted三法对照为主；模态组合/视觉替换/质量规则可压成一张补充表或短段。强调probe仅辅助、同源相关、粗区间回退、hard单代表的取舍。

### 6.3 Q2建议6个小节

1. **任务定义与数据协议。** 分类/回归目标、类别0/1/2、train/valid划分、padding/native zero/人工缺失、输入维度。
2. **基线与轻量残差池化。** 均值、attention、gamma残差、三路融合及双头公式；说明冻结基座、额外883参数。
3. **目标函数和求解。** train-only平衡权重w_c=N/(3n_c)、CE+SmoothL1；AdamW 1e-3、weight_decay 1e-4、batch128、最多80epochs、patience12；B0/P2选模及早停差别按实际代码写，完整训练样本、无缺失增强。
4. **缺失评估设计。** 45+9条件、长度取整、前中后位置、场景宏平均、三个训练seed；将S/R与官方四指标分开。

6. **附件3结果和适用边界。** 填入完成后真实CSV统计、类别计数/比例、回归分布、预测实例、ID一致性与文件名；无标签不能报Accuracy/F1/MAE/Pearson。最后指出开发验证、小收益和未覆盖缺失分布的限制。

## 7. 结论—证据对应及审稿风险

| 计划结论 | 证据 | 允许程度 |
|---|---|---|
| Q1对全部100条生成可追溯三模态表示 | 历史validation汇总、代码与典型trace | 可写历史结果；恢复完整产物并复核后才能确认提交闭环 |
| hard对齐更易复核且预测表现与对照接近 | 正时间交集规则、152个nearest异常映射、25折辅助表 | 支持；不能写预测最优/显著优于 |
| 三模态融合必然提高识别性能 | T+A分类优于T+A+V，回归权衡 | 不支持，应删除 |
| P2轻量且提高平均缺失综合分数 | 883附加参数、三seed配对结果及同clean选择敏感性 | 支持有限陈述 |
| P2比B0更不怕缺失、退化更小 | clean→missing降幅实际更大 | 不支持，应改为绝对缺失性能的小幅提高 |
| P2所有场景/所有seed更好 | seed44近持平、原生全零子组下降 | 不支持 |
| 已满足附件3专项预测提交 | 当前SEALED | 不支持；先完成最终推理CSV |
| Q1/Q2共享同一特征训练流水线 | 数据/维度/时间位置语义不同 | 不支持；用两条输入路径说明 |

五维自审：贡献定位可通过（可追溯接口、轻量池化取舍）；写作清晰度需补正文和数字；实验强度足够支撑有限结论、不足以支持显著普适优势；评价完整性尚缺官方输出闭环；方法合理性基本通过但需明确时间锚点、同源CV和零值语义。
