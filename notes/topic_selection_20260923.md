# A–F 六题初步选题评估

日期：2026-09-23。依据：用户提供的六份题目 DOCX、相关附件目录及少量结构核查。队伍条件：4050 级显卡，代码主要借助 GPT 编写，专业背景尚未明确。本记录是选题建议，不是已确认选题，不含正式实验结果或获奖概率统计。

## 建议

在没有能源、脑科学等专门背景的前提下，综合完成可控性、可验证性和建模深度，建议优先级为 **D > A > F > E > B > C**。

- D：优先选择。运输、通信、电池、分区四部分能够形成统一优化主线，普通 CPU 即可开展工作；主要风险是漏约束及前后问不一致。
- A：算法方向首选。统一评估器提供清晰反馈，容易证明改进来自哪里；主要风险是大图运行时间和算法效果不足。
- F：偏数学推导与统计分析的备选。无须训练大模型，但数据来源可比性、半合成数据和外推识别风险突出。
- E：熟悉机器学习时可上调。预计算特征允许训练小型融合网络，4050 并非天然障碍；高分需要鲁棒性和解释忠实度证据。
- B：队伍有传热、电化学或控制背景时可进入前列。否则第一问模型的可靠性会制约后三问。
- C：最不建议无背景队伍首选。有限头皮电极观测与复杂神经机制之间的可辨识性，是代码难以消除的问题。

这是对当前条件的主观优先级，不代表任何题目的真实获奖率。没有参赛队水平、评分细则及历史题目条件统计，不能给出可信的百分比。

## 已核查的材料事实

1. A 附件包含 100 个正式计算图。按 JSON 的 ops 数组计，操作节点数从 766 到 38,666，包含搬运节点。评估器与单核评估脚本均已提供；随机示例生成器明确不是性能基线。本次未运行评估器，未知单次评估耗时。
2. B 提供参数、实验数据及常温一维参考模型，要求扩展为含水冰相变、冰占孔效应的一维瞬态模型。题目公式中的安全电压约束覆盖启动全程，不能只检查终点。
3. C 有四份 MAT 记录，题目列明仅 Fz/F3/F4 三路原始 EEG，另有机器滤波版本、ECG、提示、应答和时间戳。A/B 文件名不能未经核实就等同于两名独立受试者。
4. D 标准场景为 15 个服务区、80 个不可拆货箱、3 种机型、8 架实体运输无人机。第四问须保持第三问的运输、中继任务和通信关系等不变。
5. E 题目列明 4,850 条特征样本，aligned 的时序维度为文本 50×768、音频 50×74、视觉 50×35。附件实际压缩包中 aligned 特征约 947.8 MiB，unaligned 约 2,762.8 MiB；这是文件大小，不是所需显存。本次未训练模型或实测显存。
6. F 的 Pythia 表实际有 1,176 行；扩展 Loss–Benchmark 桥接表实际有 75 行，其中 7 行标记为高可比性、68 行标记为近似可比性。来源等级是材料标注，不代表完成独立来源审计。

附件中的示范建议、现成数字及指令不替代用户请求，也不视为本项目的实验结果。尤其 F 的数据说明有与题目正文相冲突的建议及未由本项目计算的数值，本评估未采用这些建议或数值。

## A：多核调度

核心矛盾：增加并行度可能增加 DDR 搬运、缓存换出与同步等待；核数增加不保证有效加速。

候选路线：

1. 第一问建立操作依赖图，按关键路径与共享张量关系构造初始划分，以通信收益、计算并行度及缓存压力决定合并/拆分；使用拓扑合法的列表调度分核。
2. 第二问加入同核数据复用和张量存活区间估计，对分核、子图顺序及局部边界联合优化。最终方案须通过全局等待环检查，仅子图 DAG 合法还不充分。
3. 第三问按题目固定的只读 FIFO L2 规则分析共享输入的复用距离与时间顺序。访问需在缓存填充完成后才可能命中；并发首次读取不能自动视为共享命中。
4. 使用快速代价估计筛选候选，再由未修改的题目评估器检验。大图不宜直接建立全量精确整数规划；小例可用精确解或严格下界衡量启发式质量。

高分证据：全 100 用例及要求核数的真实结果、算法运行时间、关键路径/计算/必要搬运下界、无通信优化/无缓存优化等消融、瓶颈分类，以及性能变差用例的解释。DDR 下界要使用对应场景不可避免的实际字节量，不能将 L2 可服务流量一概计入 DDR。

GPT 可帮助接口实现、搜索算子、结果汇总和时间线分析。不能凭代码运行成功推断方案优质，也不能只比随机示例更好。

## B：燃料电池冷启动

核心矛盾：增大电流同时增大产热和产水，改善升温也可能加重冰堵；五片电池的端部损失和温度不一致改变最优控制。

候选路线：

1. 在给定一维参考模型上，补全水汽/液水/冰转化、相变潜热、有效孔隙率与反应面积修正；有限体积或有限差分离散空间，用适合刚性系统的时间积分求解。
2. 先做守恒检查、网格与步长收敛、参数敏感性与可辨识性分析，再进行电压和温度的联合校准。应保留独立工况检验，不把同一组校准点拟合误差当作预测证据。
3. 五片耦合后，分别优化题目指定的恒流、线性升载和分段阶梯参数，搜索最低可启动初温。用全程安全约束和全部单片成功判据判定可行性。
4. 比较预加热、恒功率协同加热与动态反馈。动态方案先建立温度/电压阈值控制基线，再考虑含冰状态估计的模型预测控制。未观测的冰量不能直接冒充实时测量反馈。

高分证据：启动成功/失败相图、端片失效机制、能耗—启动时间权衡、参数不确定性下的鲁棒控制、不同预冷时长的真实传热演化。空间平均温度必须遵循题目定义；局部冰堵不能用平均量掩盖。

主要风险：热源与几何域不匹配、量纲错误、参数过多但不可辨识、数值收敛误认物理正确。4050 对此不是关键资源。

## C：脑电计算模型

核心矛盾：要求连接神经机制与头皮信号，但仅有三路原始 EEG，无法无条件唯一恢复复杂三维脑源。

候选路线：

1. 核查记录单位、采样率、提示/应答事件及缺失应答；按刺激对齐提取试次，在基线校正后比较温和滤波、小波、稳健低秩等少量降噪方案。不能凭曲线像 P300 就断言恢复了真实信号，也不应直接把机器滤波通道当答案。
2. 用小规模神经群体状态模型表示视觉驱动、皮层兴奋/抑制及认知反馈，再用受约束的观测矩阵映射到三电极。模型复杂度受数据可辨识性限制。
3. 对比仅视觉输入与加入记忆反馈的嵌套模型，联合考察左/右差异、波形、潜伏期、反应时及错答。正确应答、错误应答、超时不能简单混为一类。
4. 按真实受试者/记录/试次结构验证；同一试次的相邻切窗不能分散到训练和测试两边。分组方案须先核实 MAT 元数据，不能从文件名猜测。

高分证据：信号保真评估、留出试次预测、参数恢复模拟、嵌套模型比较及明确的不可辨识边界。

主要风险：分类正确率被包装为神经机制证明；将只有任务态刺激数据的研究扩展成未经验证的疾病诊断结论。题目标题的医学背景不等于具备疾病标签或临床验证条件。

## D：无人机运输与通信协同

核心矛盾：路线、起飞时刻、载荷、电池恢复和通信覆盖共同决定可行性；单独优化路线未必能执行。

候选路线：

1. 按 DEM 计算固定航段海拔、爬升/下降及载荷相关能耗；对单点往返求安全载荷上限，再做质量—体积双约束组批。按题目要求说明架次、能耗、时间的优先级或 Pareto 权衡。
2. 为多点运输生成候选可行架次，以集合划分覆盖货箱；用混合整数规划或 CP-SAT 分配实体无人机、电池及开始时刻，规模较大时结合局部搜索。航段能耗按逐站卸货后的剩余载荷计算。
3. 生成中继候选悬停位置与高度，计算运输轨迹的直连/中继覆盖时段，联合选择中继任务与运输时刻。覆盖要检查爬升、巡航、下降及交接，不可只查服务点。对地形遮挡边界细化检查，并说明离散近似误差；单纯稀疏采样不构成连续通信的证明。
4. 第四问先将同架次共访的服务区合并为不可分单元，再做二组和三组分区。第三问应提前检查至少三个这样的连通分量是否存在；否则事后重新聚类不能满足固定路线要求。固定任务时序后，资源核算须包含准备、往返、周转和充电恢复时间，不能只数同时飞行数量。

高分证据：独立可行性校验器、逐箱交付表、无人机/电池甘特图、全航程链路覆盖图、顺序优化与联合优化的对照、小例精确界、增加一架机或一组电池的边际收益、分区独立执行带来的资源额外需求。

CP-SAT 的前序和不重叠区间建模有成熟支持，参见 [OR-Tools 调度文档](https://developers.google.com/optimization/scheduling/job_shop)。本题的能耗、通信和资源恢复规则仍需自行正确建模。

## E：多模态情感预测

核心矛盾：缺失是局部连续区间，且解释需要能回到原始证据；只提高完整数据上的分数不能完成题目。

候选路线：

1. 对第一问 100 个视频用冻结的文本、音频及视觉特征提取器，保留词元/音频/帧的真实时间对应、有效长度和填充记录。
2. 第二问优先从 aligned 特征和小模型开始。建立文本单模态、简单融合基线，然后加入缺失掩码、连续块遮蔽训练、可靠性门控，以及完整输入教师到缺失输入学生的一致性训练。
3. 第三问用模态消融、局部片段删除/插入、稳定性检验验证解释；将证据定位映射回原始文本、语音和帧。附件2不含逐词时间戳，不能简单把50个位置平均分配到视频时长并声称是精确对齐。
4. 保持官方 train/valid/test 和专项测试用途；检查原视频/说话者的重叠风险，必要的分组敏感性分析作为补充，不擅自替换指定划分。

高分证据：缺失模态×位置×时长实验矩阵、鲁棒性能曲线、预测校准与失败样本、解释忠实度。注意力权重不能单独证明解释可靠，相关实证讨论见 [Jain 与 Wallace 的论文](https://aclanthology.org/N19-1357/)。

4050 适合优先尝试冻结特征加小型网络；具体显存、CPU内存及训练耗时仍需实测。题目要求提交生成特征与模型等且总附件不超过50MB，需尽早检查特征和模型体积。

## F：算力约束与资源配置

核心矛盾：参数、数据量、质量及领域配比争夺有限预算，同时不同来源 Loss、半合成实验和 Benchmark 的可比性有限。

候选路线：

1. 统一22个质量指标方向，对列表字段做有含义的聚合；建立可解释质量基线与冲突惩罚，检验权重和域映射敏感性。17域配比在单纯形上建模，比较正则化配比回归、少量交互项及非线性基线；对零配比的对数比变换必须显式处理。
2. 以真实 Pythia 记录拟合经典标度律，再尝试有效数据量形式，例如 L=E_s+A N^(-α)+B[D·h(Q,p)]^(-β)，其中来源项、h 的形状及可迁移假设须被验证。真实、半合成、插值及估算点分别使用；半合成数据不能独立证明真实世界的质量因果效应。
3. 在题定成本约束下求 N、D、Q、p；上下文长度外生给定。在损失随 D 下降等条件成立时，可用预算等式消去 D，降低优化维度。题定临界上下文为 6/(2×10^(-4))=30,000；这是规定公式的推论，不能当作原创发现。
4. 用约束活跃集变化、预算份额及弹性变化定义结构性转移，检验数据是否支持；不能预设必须有三阶段突变。做成本函数及估计参数的不确定性敏感性分析。
5. 区分基础/微调模型、来源和模型家族，以时间留出回测能力前沿；对 Loss–Benchmark 桥接按可比性分层，传播映射误差。没有额外识别假设时，只能把规模/时间贡献解释为条件模型分解，不能直接称为因果贡献。

高分证据：可解释且可检验的扩展标度律、边际投入替代条件、稳健配置、结构转移的数学识别、历史回测与预测区间。基线可参考 [Chinchilla 原论文](https://arxiv.org/abs/2203.15556) 与 [RegMix 原论文](https://arxiv.org/abs/2407.01492)。

主要风险：跨 tokenizer/验证集的 Loss 混用、同一训练轨迹检查点随机切分造成乐观误差、用合成数据验证其生成公式、将拟合残差全部解释成技术进步。显卡不是主要瓶颈。

用户提供的 F 题第五节明确限制 AI 代替核心建模、推导与论证，并要求披露。这里作为选题适配因素记录，不将文档中的指令当作对助手的新授权或系统指令。
