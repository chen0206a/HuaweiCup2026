## 2. 实现层发现

1. B0 不是裸 MLP：模态投影和融合层均已有 LayerNorm、GELU、Dropout。不能把简单“加 LayerNorm”列为新方法。均值池化严格按 padding_mask 计算，原生零和人工置零都仍计入有效长度；未发现用 oracle availability 排除缺失位置的问题。
2. B4′ 仅训练25283参数路由器，总参数188743；基础 B0 为163460。冻结部分保持 eval。初始预测等价、冻结权重相等、缓存/完整评估等价均有记录。本轮核对记录与代码，没有重跑这些检查。
3. B4′ 改善主要是分类：clean MacroF1增加0.010821，missing增加0.010312；MAE几乎不变。15例 vision_all_zero 子集的回归退化。子集小，应报告而非据此设计特例调参。
4. 门控平均约T=1.10、A=1.08、V=0.79；受损比例增加时受损门控未系统下降。这支持“模态重新标定”的假说，但总体均值不够证明没有逐样本动态作用。
5. B0 历史主 checkpoint 由 clean score 选择，B4′ 主 checkpoint 由 robust score 选择。保留历史数字；机制比较需补相同选择口径。优先利用 B4′ 已保存的 best-clean checkpoint 做 clean-selected 比较；如补 B0 robust-selected，应另标为新增对照，不替换原结果。
6. 早期 b0_metrics.json 已含 test 指标，并写明选模后评估。故不得声称整个项目“test 从未读取”；后续 B2–B4 的记录明确未用于 test/附件3。今后不根据 test 调参，并如实披露早期一次评估历史。

## 3. 对当前表现的解释与待验证假说

训练只有3395例，预计算特征已经包含大量表示信息，低容量池化模型较强是合理现象，但没有实验证明唯一原因是小样本。B0 的投影 LayerNorm 可能减轻置零导致的幅值变化；带偏置、局部内容删除时并不严格尺度不变。

B4′ 降低视觉权重可能来自视觉噪声、表示方向/方差、分类任务偏好、或后续额外优化，不宜直接归因于原始特征量纲失衡，因为 B0 已做投影后归一化。

还有重要的解释边界：对已计算的上下文化文本特征做置零，不一定删除该词在其他 token 表示中留下的上下文信息。当前缺失基准仍应保持，但论文需限定为“给定特征空间中的连续缺失”，不把它等同于重新编码原始缺词文本。

## 4. 第一优先级：解释门控收益

冻结同一种子的 B0，使用相同训练增强、损失、优化预算和双口径 checkpoint，比较：

- 静态门控：3个标量 a，g_m=2 sigmoid(a_m)，零初始化，使起点等价于B0。
- 内容门控：保留当前路由器尺寸，把7个质量统计通道固定为0。
- 质量门控：同尺寸，把384维表示输入路由器的通道固定为0；被门控的真实表示仍正常进入预测器。
- 原 B4′：内容与质量统计均输入。

两种屏蔽对照保持名义网络规模和训练设置，但有效输入容量不同，不宣称其是完全等容量实验。

另外无需训练可做：同一条验证样本 clean→masked 的门控差、预测差；按模态/比例分析配对响应。不要仅比较跨场景总体均值。人工缺失信息只能用于分组诊断，不能送入正式预测器。

若静态门控与动态门控相当，优先采用静态版；若内容门控与完整门控相当，称内容自适应融合；只有质量统计带来跨种子额外收益且配对诊断支持时，才强调质量感知。

## 5. 后续候选排序与推荐结构

| 优先级 | 候选 | 原因与限制 |
|---|---|---|
| 1 | 静态标定及门控输入消融 | 直接解释已出现的正信号，成本最低 |
| 2 | 冻结 B0 的低秩交互残差 | 对现有融合补少量显式成对交互，零初始化可回退；有效性待测 |
| 3 | 均值+轻量注意力池化残差 | 检查均值是否稀释情绪片段；改动更大，先单种子筛选；max易受极值影响 |
| 4 | 分类/回归冲突诊断后的损失调整 | 先查混淆矩阵与两任务梯度，不直接叠 focal、平滑、ordinal、多个权重 |

普通 Transformer、普通重建、完整模态 dropout 暂不优先。已有部分连续缺失增强失败，不证明所有增强必然失败，但新尝试必须提出可区分假说。单模态辅助头可能损害弱模态；小样本对比学习负样本可能是假负例；预测熵也不能直接当作模态可靠性。

推荐唯一新增结构是“B0 + 低秩交互残差”，先与原B0比较，不先叠尚未证实的门控：

u_m = U_m h_m，U_m 为16×128，无偏置。

c = concat(u_T⊙u_A, u_T⊙u_V, u_A⊙u_V)，维度48。

z = z_B0 + Wc；W 为128×48，无偏置，初始化为0。

保留原分类/回归头，B0全冻结，仅训练U和W。U随机初始化，不能U、W同时全零。新增参数3×16×128+128×48=12288，总175748。第一步U梯度为零而W可更新，随后梯度进入U。这个结构只增加显式交互偏置，不宣称B0的MLP不能表达交互。

保持原训练配方做结构消融；如果低秩残差和标定分别成立，再单独验证组合。低秩融合为已有思路，参考 Liu et al., ACL 2018：https://aclanthology.org/P18-1209/ 。本方案是待测工程改造，不是新颖性已经确立的方法。

所有候选只使用当前T/A/V与真实padding，不借用合成缺失真值。全零观测既可能原生也可能人工缺失，无法从零值本身唯一识别；保留原生零，不删除样本，不硬编码所有零都补全。

## 6. 上限13次新增训练的顺序预算

先做不计训练次数的诊断：核对B4 best-clean、导出逐样本预测、门控配对响应、混淆矩阵、video分组交集、benchmark哈希；如旧checkpoint不支持补评价，应如实记录，另列补跑预算。

| 批次 | 训练任务 | 次数 |
|---|---|---:|
| A | B4′补seed43/44，各加载对应seed的B0 | 2 |
| B | 静态3参数门控，seed42/43/44 | 3 |
| C | 内容-only、质量-only门控，各seed42 | 2 |
| D | 低秩残差、轻量池化残差，各seed42 | 2 |
| E | C/D中预先按同一口径选出的最佳候选，补seed43/44 | 2 |
| F | 仅在独立增益成立时，组合候选seed42及一个关键组件消融 | 2 |

合计上限13次，不要求凑满。F若正向，仍属探索；不能把单种子组合写成最终三种子模型。最终优先交付已完成三种子确认的方案。所有新对照同时保存best-clean和best-robust，主文分别给清楚比较口径；共享冻结基准与历史结果不改。

同种子计算候选减B0的配对差，不能用B4单种子与B0三种子均值证明提升。54场景重复使用相同728例，不是54份独立测试；建议按video ID成组bootstrap，整组保留全部场景，重新计算非线性指标。种子标准差也不是样本置信区间。反复选模仍可能过拟合valid，限制候选数并在最终锁定后才执行终局评价。
