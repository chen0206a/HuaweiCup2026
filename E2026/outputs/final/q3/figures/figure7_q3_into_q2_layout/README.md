建议图注：**图7 情感预测与层级证据归因框架。** 三模态特征经双路池化与融合获得情感类别和强度预测；HEAF 从模态贡献、模态交互和连续时间遮挡三个层级组织解释，并通过关键区间删除与随机删除对照检验解释有效性。文本证据可回溯至原文，音频与视觉只报告特征槽位区间；左侧媒体素材仅作输入示意。
