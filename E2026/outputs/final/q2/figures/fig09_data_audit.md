## 四个面板

- **(a) 多次初始化的稳健得分**：展示三个随机种子下 B0 与 P2 的配对结果。配对增量依次为 `+0.005600`、`+0.003791`、`−0.000090`；均值为 `+0.003100`，三 seed 样本标准差为 `0.002907`。即 2/3 个 seed 为正，增益较小并随初始化变化；没有计算显著性或 p 值。
- **(b) 验证集混淆矩阵**：保留 B0 与 P2 并排比较，使用 clean valid 种子42的已有预测计数，样本数 `n=728`。类别顺序为消极、中性、积极；每格给出计数和按真实类别归一化比例，共用同一浅蓝至深蓝色标。
- **(c) 不同缺失场景的选择得分**：分组柱形图显示 B0 与 P2 的 selection score。对每个模型分别先在一个 seed 的对应场景内求均值，再以三个 seed 汇总均值和样本标准差；黑点表示每个 seed 的场景内均值，误差线表示跨 seed 样本标准差。四类每 seed 场景数分别为：单模态缺失45、双模态缺失9、高比例缺失18、位置扰动54。分类之间有重叠，并非互斥组。柱形从零起始；图上 Δ 为 P2 均值减 B0 均值，避免用截断坐标夸大很小的差异。
- **(d) 视觉全零子集**：展示验证集原生视觉全零子集（每个模型/seed `n=15`）的准确率和宏平均 F1。柱为三 seed 均值，误差线为样本标准差，点为单 seed 结果。此处用于呈现小样本特殊输入下的薄弱边界，不代表总体性能结论。
