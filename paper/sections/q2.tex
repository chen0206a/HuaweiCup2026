\section{问题二：局部模态缺失条件下的鲁棒多模态情感预测}

\subsection{对比模型与实验设置}
为检验轻量时序建模在局部连续模态缺失下的作用，本文在赛题提供的 aligned-50 预计算特征上比较三种公开方法适配模型与本文模型。三种公开方法分别为张量融合网络 TFN\cite{zadeh-etal-2017-tensor}、多模态 Transformer MulT\cite{tsai-etal-2019-multimodal}，以及模态不变与模态特异表示模型 MISA\cite{hazarika-etal-2020-misa}。数据划分沿用附件 2 的训练集与验证集，样本数分别为 3395 和 728；每种方法使用随机种子 42、43、44 独立训练，表中报告三次结果的均值及样本标准差。分类任务采用 Negative、Neutral、Positive 三类标签，回归任务预测连续情感强度。评价指标包括 Accuracy、Macro-F1、MAE 和 Pearson 相关系数。

公开方法均依据其核心结构在 aligned-50 输入上重新实现并训练：TFN 保留张量外积融合思想；MulT 保留方向性成对跨模态注意力；MISA 保留 shared/private 表示分解及差异、CMD 和重构辅助目标。由于输入接口和训练流程经过适配，本实验不等同于原论文设置的完整复现。实验没有使用外部情感数据或外部任务权重。实现参考的 MulT 与 MISA 官方仓库采用 MIT 许可证；TFN 参考仓库未提供许可证文件，因此本文仅依据论文独立实现张量融合结构，未复制该仓库源码。

在当前 aligned-50 架构适配和统一训练预算下，本文模型在 clean validation 的四项均值指标上均高于三种公开方法适配模型，且参数量较小。TFN 参数量最大，但在本实验中没有体现出相应的性能优势；MulT 的 Accuracy 与 Pearson 表现较均衡；MISA 的 Macro-F1 与 Pearson 保持在可用水平，但回归误差较高。对 MISA 三个 checkpoint 的回归路径复核表明，训练与验证使用同一原始连续标签尺度，回归输出维度及 loss 对齐正确，回归头梯度非零，独立复算的 MAE 与 Pearson 与评价流程一致。因此，本实验保留其实际结果，不通过额外调参改变结果。其表现说明预测排序关系尚可，而绝对数值校准较弱。
